# GraphMuse

A Python web app that visualizes NBA player statistics using real-time data.

## Features
- View top NBA players by points, assists, rebounds, steals, or blocks
- Toggle between total and per game stats
- Choose how many players to display
- Each player's bar is colored to match their team

## Built With
- Python
- Pandas
- SQL (sqlite3)
- Plotly
- Dash
- nba_api

## How to Run

1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `python nba_stats.py`
4. Open your browser and go to http://127.0.0.1:8050
